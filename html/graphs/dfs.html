Depth-First Search

A grid traversal that explores deeply through open cells before backing up to try another route.

DFS is the first pathfinding view worth building because it exposes the core engine pieces: open cells, walls, active cell state, visited cells, stack behavior, and backtracking.

Quick Facts

Time: \(O(V + E)\) Memory: \(O(V)\) Traversal Stack Backtracking Unweighted
Best for

Maze-like exploration, reachability checks, and testing the grid engine before shortest-path algorithms arrive.

Watch out for

DFS does not guarantee shortest paths in an unweighted grid. BFS is the usual tool for that.

Step by Step

  • Put the start cell on the stack.
  • Pop the top cell and visit it if it is new.
  • Inspect each open neighbor of the current cell.
  • Push unvisited neighbors onto the stack.
  • When a route runs out, backtrack to the next stack item.

Explanation

How DFS Works

Depth-First Search starts from S and follows one route through open cells as far as it can. When no new neighbor is available, it backtracks and resumes from the most recent unfinished route.

On a grid, each open cell is a vertex and each legal move is an edge. DFS checks each reachable cell and neighbor, so the traversal still costs \(O(V + E)\).

function dfs(graph, start):
    stack = [startCell]
    visited = empty set

    while stack is not empty:
        cell = stack.pop()
        if cell in visited:
            continue
        mark cell visited
        if cell is target:
            return path
        for neighbor in openNeighbors(cell):
            if neighbor not in visited:
                stack.push(neighbor)

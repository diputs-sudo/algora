Graph algorithm

Bellman-Ford

A shortest-path algorithm that repeatedly relaxes every edge and remains reliable when weights can be negative.

Bellman-Ford makes repeated relaxation visible: each pass checks every reachable edge, improving distance values until no better path remains.

Back to Graphs

Quick Facts

Time: \(O(VE)\) Memory: \(O(V)\) Shortest Path Edge Relaxation Negative Weights Negative Cycles
Best for

Graphs with negative edge weights where Dijkstra cannot safely guarantee shortest paths.

Watch out for

A reachable negative cycle means no finite shortest path exists for the affected vertices.

Step by Step

  • Set the start distance to zero and all others to infinity.
  • Scan every reachable edge during the current pass.
  • Relax an edge when its candidate distance is smaller.
  • Repeat for at most (V-1) passes.
  • Scan once more to detect a reachable negative cycle.

Explanation

How Bellman-Ford Works

Bellman-Ford stores the best known distance to every reachable cell. It relaxes every legal directed move, replacing a distance when a cheaper candidate is found.

After (V-1) passes, every shortest simple path has had enough opportunities to propagate. A final pass reveals whether a reachable negative cycle can still improve a distance.

Pseudocode

function bellmanFord(graph, start):
    distance[start] = 0

    repeat V - 1 times:
        changed = false
        for (current, neighbor, cost) in edges(graph):
            candidate = distance[current] + cost
            if candidate < distance[neighbor]:
                distance[neighbor] = candidate
                parent[neighbor] = current
                changed = true
        if not changed:
            break

    for edge in edges(graph):
        if canRelax(edge):
            return negativeCycle

    return reconstructPath(parent, target)

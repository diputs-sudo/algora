D* Lite

Keep a shortest path ready while you edit the map.

D* Lite plans backward from the target, then repairs only the vertices affected by an obstacle edit. The workspace keeps g-values, rhs-values, and the priority queue alive between repairs.

Explanation

How D* Lite Works

D* Lite maintains two values for each vertex. g is the current path estimate, while rhs is a one-step lookahead estimate. A vertex is consistent when the two values agree.

When the map changes, D* Lite places affected vertices back into a priority queue and repairs the policy from the goal toward the start. The previous search work remains useful.

Pseudocode

function dStarLite(graph, start, target):
    rhs[target] = 0
    queue.push(target)

    while queue is not empty:
        u = queue.popSmallestKey()
        update g[u] and affected predecessors

    if a cell changes:
        update affected vertices
        computeShortestPath()

    return highlighted path when ready

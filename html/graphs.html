Available algorithms

BFS

Expands in clean waves from the start node, making shortest paths on unweighted grids easy to see.

O(V + E) Memory: O(V) Frontier Wave Essential

DFS

Follows one route deeply through a grid before backtracking, emphasizing stack behavior and explored cells.

O(V + E) Memory: O(V) Backtracking Essential

Dijkstra

Shows distance values updating as the priority queue chooses the next cheapest reachable node.

O((V + E) log V) Memory: O(V) Weighted Terrain Workspace

A*

Balances g, h, and f scores while contrasting open and closed sets as the heuristic pulls the search forward.

Heuristic-dependent Memory: O(V) g + h = f Workspace

Greedy Best-First

Uses only the heuristic estimate, making it a sharp contrast with A* when the path looks tempting but costly.

Heuristic-dependent Memory: O(V) Heuristic Only High Priority

Bidirectional BFS

Runs two simultaneous frontiers from start and goal so the meeting point becomes the key visual moment.

O(V + E) Memory: O(V) Two Frontiers Workspace

0-1 BFS

Highlights deque pushes to the front or back as zero-cost and one-cost edges shape the next expansion.

O(V + E) Memory: O(V) Deque Workspace

Bellman-Ford

Turns each pass over the edge list into visible relaxation work, including support for negative edge weights.

O(VE) Memory: O(V) Negative Weights Workspace

Floyd-Warshall

Moves away from the grid and into an all-pairs matrix where each intermediate node can improve distances.

O(V³) Memory: O(V²) All-Pairs Matrix Workspace

Johnson's Algorithm

Shows graph reweighting first, then repeated Dijkstra runs across the adjusted edge costs.

O(VE + V² log V) Memory: O(V²) Reweighting Advanced

IDA*

Repeats depth-first searches while the f-bound increases, making each threshold feel like a widening lens.

O(b^d) Memory: O(d) Iterative Bound Workspace

D* Lite

Centers the dynamic environment: obstacles change, priorities update, and the path repairs instead of restarting.

Incremental Memory: O(V) Replanning Workspace

Jump Point Search

Emphasizes grid pruning and jump points so the search feels dramatically smaller than plain A*.

Grid-dependent Memory: O(V) Jump Points Workspace

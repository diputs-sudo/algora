Hash Table Lookup

Build a value-to-index table, then find the target through its bucket chain.

Hash Table Lookup trades extra memory for fast average access. The lab builds an open-addressed table, shows collisions, then hashes the target and follows the same probing rule until it finds the key or reaches an empty bucket.

Hash Table Lookup Lab

Step by Step

  • Allocate a bucket array with extra empty space.
  • Hash each array value to its starting bucket.
  • If the bucket is occupied, probe forward until a slot is available.
  • Hash the target with the same function.
  • Follow the probe chain until the key is found or an empty bucket ends the search.

Explanation

How Hash Table Lookup Works

A hash table uses a hash function to map a key to a bucket. For this page, each value is the key and the stored value is the first array index where that key appeared.

Collisions happen when two keys choose the same bucket. This lab resolves collisions with linear probing: check the next bucket, then the next, until the key or an empty slot appears.

Pseudocode

function hashLookup(array, target):
    table = empty hash table
    for index, value in array:
        if value not in table:
            table[value] = index
    if target in table:
        return table[target]
    return -1

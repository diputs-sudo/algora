Meta Binary Search

A sorted-array search that builds the target position bit by bit with binary lifting.

Meta Binary Search searches for the lower-bound index by testing powers of two. Each accepted bit moves the base index right, and each rejected bit leaves the base in place.

Step by Step

  • Start with a base index before the array.
  • Choose the largest useful power-of-two bit.
  • Test whether base plus that bit is still smaller than the target.
  • If it is smaller, keep that bit by moving the base.
  • After all bits are tested, check base plus one.

Explanation

How Meta Binary Search Works

Meta Binary Search uses powers of two to build an index. It asks whether adding the current bit keeps the candidate below the target. If yes, the bit is kept. If no, the bit is skipped.

This gives the same \(O(\log n)\) search behavior as Binary Search, but the mental model is closer to binary lifting.

Pseudocode

function metaBinarySearch(array, target):
    position = -1
    bit = largest power of two below array.length
    while bit > 0:
        next = position + bit
        if next < array.length and array[next] < target:
            position = next
        bit = bit / 2
    candidate = position + 1
    if candidate < array.length and array[candidate] == target:
        return candidate
    return -1

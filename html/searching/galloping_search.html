Galloping Search

A sorted-array search that gallops forward by doubling jumps, then finishes inside the bracket.

Galloping Search is the range-discovery pattern used by merge algorithms such as TimSort. It quickly skips over values that are too small, then uses Binary Search once the target has been bracketed.

Step by Step

  • Check the starting value.
  • Double the jump while the jumped value is smaller than the target.
  • Stop once the jump crosses the target or reaches the array end.
  • Binary search inside the bracket between the previous jump and the current jump.
  • Return the found index or report that the bracket is empty.

Explanation

How Galloping Search Works

Galloping Search first moves through sorted values with jumps of 1, 2, 4, 8, and so on. When the current value is no longer smaller than the target, the target can only be inside the last jumped range.

The final phase is Binary Search within that range, so the whole lookup stays \(O(\log n)\) while being very fast when the target is near the starting position.

Pseudocode

function gallopingSearch(array, target):
    if array is empty:
        return -1
    if array[0] == target:
        return 0
    previous = 0
    jump = 1
    while jump < array.length and array[jump] < target:
        previous = jump
        jump = jump * 2
    left = previous + 1
    right = min(jump, array.length - 1)
    return binarySearch(array, target, left, right)

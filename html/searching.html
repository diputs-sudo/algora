Searching

Classic algorithms for finding a target in a single array.

Linear Search

Checks each element from left to right and works on any array shape.

O(n) Any Input Memory: O(1)

Binary Search

Repeatedly halves a sorted array until the target is found or the search space disappears.

O(log n) Sorted Input Memory: O(1)

Jump Search

Jumps through blocks in a sorted array, then linearly scans the block where the target may live.

O(√n) Sorted Input Block Search

Sentinel Linear Search

Places the target as a temporary sentinel at the end to reduce boundary checks during a linear scan.

O(n) Any Input Boundary-light

Interpolation Search

Estimates the likely target position, which can be very fast on evenly distributed sorted values.

Avg: O(log log n) Worst: O(n) Even Distribution

Exponential Search

Expands a range by powers of two, then finishes with binary search inside that range.

O(log n) Range First Sorted Input

Fibonacci Search

Uses Fibonacci offsets to narrow a sorted array without choosing the exact middle each time.

O(log n) Sorted Input Advanced

Ternary Search

Splits a sorted range into three parts and decides which third can still contain the target.

O(log n) Three-Way Split Sorted Input

Uniform Binary Search

Uses a precomputed step table to search sorted arrays with a regular access pattern.

O(log n) Sorted Input Step Table

Galloping Search

Grows the search window exponentially before narrowing it, a pattern often used while merging runs.

O(log n) Range First Sorted Input

Meta Binary Search

Builds the answer index bit by bit, using binary lifting over sorted positions.

O(log n) Binary Lifting Sorted Input

Rotated Sorted Array Search

Adapts binary search by detecting which half is sorted after an ordered array has been rotated.

O(log n) Rotated Input Binary Variant

Bitonic Array Search

Finds the peak in an increasing-then-decreasing array, then searches each side with the right direction.

O(log n) Peak Search Specialized

Hash Table Lookup

Builds a value-to-index table first so later target lookups are fast on average.

Build: O(n) Lookup: O(1) Memory: O(n)

Quickselect

Finds the k-th smallest value using partitioning, without fully sorting the array.

Avg: O(n) Worst: O(n²) Selection

Parametric Search

Binary searches over possible answers when a monotonic feasibility check tells us what is too small or large.

Answer Space Monotonic Check Advanced

Fractional Cascading

Links multiple sorted lists so repeated related searches can reuse positional information.

Multi-List Search Advanced Linked Catalogs
